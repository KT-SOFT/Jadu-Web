# 자두 음악 웹앱

[자두 열기](https://kt-soft.github.io/Jadu-Web/?v=20261105-play7)

아이폰 Safari 또는 Brave에서 사용합니다. 음악 파일 대신 YouTube 주소를 이 기기에 저장합니다. Safari의 공유 → 홈 화면에 추가로 설치 서명 없이 사용할 수 있습니다.

## 화면과 사용법

- 가로: 왼쪽 YouTube 화면, 오른쪽 검색·저장 목록. 세로: 위쪽 YouTube 화면, 아래쪽 목록.
- 검색칸 왼쪽 YouTube 로고를 누르면 새 탭을 열지 않고 자두 안의 공개 동영상 목록으로 돌아옵니다. 전체·뉴스·팟캐스트·음악·믹스 분류를 고를 수 있습니다. 최근 재생은 자두에서 재생한 동영상이며 유튜브 계정의 비공개 기록을 가져오지 않습니다. 로고를 눌러도 오른쪽 저장 목록은 유지합니다.
- 대기·검색 화면에는 썸네일 목록이 나옵니다. 곡을 누르면 같은 자리에서 공식 YouTube 재생기로 재생합니다. ‘검색 목록’과 ‘재생 화면’으로 오갈 수 있습니다.
- 양쪽 검색칸에서 노래·가수를 검색하면 공개 YouTube 결과가 최대 20개 표시됩니다. 실제 검색 결과 수를 표시합니다. 영상·재생목록 주소도 사용할 수 있습니다.
- 목록의 곡 제목을 한 번 누르면 바로 재생됩니다. 행별 삼각형 버튼은 없앴습니다. 체크박스는 저장·삭제용 여러 곡 선택에 사용하며 재생하지 않습니다.
- ‘검색 결과 / 저장 목록’으로 목록을 전환합니다. ‘저장목록 열기’는 이 기기에 보관한 곡을 보여줍니다. ‘노래 저장’은 선택한 주소를 저장합니다.
- ‘유튜브 보기 / 목록 보기’는 공통 상단에 있습니다. 설정 창은 표시하지 않습니다. 사진의 영상 아래 추가 이동·음량 버튼 줄은 넣지 않았습니다.
- 자두는 우측 상단의 작은 그림입니다. 누르면 기존 고양이 녹음으로 야옹 합니다. 옆의 ‘야옹 소리’를 끄거나 켤 수 있고 선택은 저장됩니다. 이번 화면에는 AI 대화 입력창을 표시하지 않습니다.
- ‘유튜브 계정’은 새 탭에서 공식 YouTube로 연결합니다. 로그인 후에도 버튼 이름은 ‘유튜브 계정’입니다. 브라우저에 남은 계정으로 로그인한 뒤 자두 탭으로 돌아옵니다. 자두가 확인할 수 없는 로그인 상태를 대신 표시하지 않습니다.
- 목록 제목 오른쪽 ‘⋯ → 내 유튜브 목록’은 공식 YouTube의 개인 목록 화면을 엽니다. 계정의 비공개 목록을 자두의 기기 저장 목록에 자동으로 가져오지는 않습니다.

## 저장과 백업

저장곡·보기 선택·소리 설정은 현재 브라우저의 기기에 보관합니다. 기존 자두 상태·대화 기록도 지우지 않습니다. 다른 기기나 브라우저와 자동 동기화하지 않습니다.

목록 제목 오른쪽 ‘⋯ → 저장목록 내보내기’로 Jadu-playlist.json을 보관하고, ‘저장목록 가져오기’로 복원합니다. 가져오기는 현재 자료를 바꿀 수 있으므로 먼저 내보내세요. 백업에는 개인 음악 주소와 이전 대화가 포함될 수 있으니 공개 저장소에는 올리지 마세요.

목록 삭제에는 확인 창이 있습니다. 웹앱은 실제 음악 파일을 다운로드하거나 PC 파일을 삭제하지 않습니다. 브라우저 사이트 자료를 지우면 저장곡이 사라질 수 있습니다.

## Brave

버튼이 모두 반응하지 않으면 이 사이트의 Brave ‘스크립트 차단’ 설정을 확인하세요. 스크립트 실행이 필요하며 광고·추적 차단과 별개입니다. 사용자는 스크립트 차단을 끈 뒤 검색·설정이 동작하고 기존 버전에서 화면을 잠가도 재생이 이어지는 것을 확인했습니다. 이번 화면 변경 후의 실제 아이폰 잠금 재생은 별도 기기 확인이 필요합니다.

[Brave 연결 안내](https://kt-soft.github.io/Jadu-Web/?v=20261105-play7&brave=1)는 공개 자두 주소만 전달합니다. 계정 정보·음악 목록·대화는 자동 전송하지 않습니다. 브라우저마다 저장 자료와 로그인은 따로 보관됩니다. 자두에 Brave의 광고 차단 엔진을 내장한 것은 아니며, 모든 광고 차단이나 백그라운드 재생을 보장하지 않습니다.

## 검색과 재생

공개 영상 제목·주소는 기존 자두 검색 서버로 조회합니다. 저장목록이나 로그인 정보는 검색 서버에 보내지 않습니다. 검색키 입력과 추가 서비스 가입은 필요하지 않습니다. YouTube 재생과 검색에는 인터넷이 필요합니다.

## 확인한 범위

2026-11-05 PC 브라우저를 직접 조작해 양쪽 검색, 썸네일 곡 선택, 실제 YouTube 재생·일시정지, 검색/영상 복귀, 검색/저장 목록 전환, 보기 체크박스, 공식 YouTube 로그인 화면 연결, 야옹 재생과 소리 끄기·새로고침 후 유지를 확인했습니다. 기존 저장곡 3개가 유지되는 것을 확인했습니다. 390×844 세로, 844×390 가로, 1280×720 화면을 확인했으며 실제 아이폰 검수와 구분합니다.

## 그림·소리 출처

기존 자두 그림·소리를 사용하며 원래 권리를 유지합니다. 전체 프로젝트를 오픈소스 라이선스로 선언하지 않습니다. ‘야옹’은 tuberatanka의 cat meow II(CC0)를 사용합니다. 원본 고지와 나머지 음원 출처·라이선스는 [음원 고지](https://kt-soft.github.io/Jadu-Web/assets/pet/audio-licenses.json)에 유지합니다.

## 이번 변경 확인

목록 제목 한 번 클릭으로 실제 영상 재생, 행별 삼각형 제거, 체크박스 선택 시 일시정지 유지, YouTube 로고의 현재 창 썸네일 복귀, 전체·음악 목록과 자두 최근 재생, 오른쪽 저장곡 3개 유지, 홈 썸네일 재생을 PC 브라우저에서 직접 조작했습니다. 유튜브 계정 상태·개인 목록을 자두 안에 연결하는 기능은 구현하지 않았으며 로그인 연동 완료로 표시하지 않습니다.
