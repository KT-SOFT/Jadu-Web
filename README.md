# 자두 음악 웹앱

[자두 열기](https://kt-soft.github.io/Jadu-Web/?v=20261105-more10)

아이폰 Safari 또는 Brave에서 사용합니다. 음악 파일 대신 YouTube 주소를 이 기기에 저장합니다. Safari의 공유 → 홈 화면에 추가로 설치 서명 없이 사용할 수 있습니다.

## 화면과 사용법

- 가로: 왼쪽 YouTube 화면, 오른쪽 검색·저장 목록. 세로: 위쪽 YouTube 화면, 아래쪽 목록.
- 검색칸 왼쪽 YouTube 로고를 누르면 새 탭을 열지 않고 자두 안의 공개 동영상 목록으로 돌아옵니다. 전체·뉴스·팟캐스트·음악·믹스 분류를 고를 수 있습니다. 최근 재생은 자두에서 재생한 동영상이며 유튜브 계정의 비공개 기록을 가져오지 않습니다. 로고를 눌러도 오른쪽 저장 목록은 유지합니다.
- 대기·검색 화면에는 썸네일 목록이 나옵니다. 곡을 누르면 같은 자리에서 공식 YouTube 재생기로 재생합니다. ‘검색 목록’과 ‘재생 화면’으로 오갈 수 있습니다.
- 양쪽 검색칸에서 노래·가수를 검색하면 공개 YouTube 결과가 처음 최대 20개 표시됩니다. 아래 ‘더 보기’를 누르면 다음 최대 20개를 기존 목록 뒤에 이어 붙입니다. 겹치는 영상은 한 번만 표시하고, 실제 누적 결과 수를 표시합니다. 마지막 결과에서는 버튼을 숨깁니다. 영상·재생목록 주소도 사용할 수 있습니다.
- 목록의 곡 제목을 한 번 누르면 바로 재생됩니다. 행별 삼각형 버튼은 없앴습니다. 체크박스는 저장·삭제용 여러 곡 선택에 사용하며 재생하지 않습니다.
- ‘검색 결과 / 저장 목록’으로 목록을 전환합니다. ‘저장목록 열기’는 이 기기에 보관한 곡을 보여줍니다. ‘노래 저장’은 선택한 주소를 저장합니다.
- ‘유튜브 보기 / 목록 보기’는 공통 상단에 있습니다. 설정 창은 표시하지 않습니다. 사진의 영상 아래 추가 이동·음량 버튼 줄은 넣지 않았습니다.
- 자두는 우측 상단의 작은 그림입니다. 누르면 기존 고양이 녹음으로 야옹 합니다. 옆의 ‘야옹 소리’를 끄거나 켤 수 있고 선택은 저장됩니다. 이번 화면에는 AI 대화 입력창을 표시하지 않습니다.
- ‘로그인’은 Google·Firebase 공식 로그인 창에 연결합니다. 실제 연결된 계정 이름·사진을 표시하고 같은 브라우저에서 새로고침해도 로그인 상태를 기억합니다. 공식 YouTube 페이지와 삽입 재생기의 쿠키·구독 상태는 별도로 관리되므로, 이 표시가 YouTube 페이지의 로그인 상태를 대신 증명하지 않습니다.
- 기본 화면의 ‘⋯ → 내 유튜브 목록’은 공식 YouTube의 개인 목록 화면을 엽니다. 공개 기본 화면에서 새 YouTube 읽기 권한을 요청하지 않습니다.
- 별도로 제공하는 개인 계정 시험 화면에서만 ‘YouTube 계정 보기’ 읽기 권한을 요청합니다. 본인이 만든 재생목록과 API가 제공하는 좋아요 목록을 조회하고, 목록의 곡을 자두 안에서 재생·기기 저장할 수 있도록 구성했습니다. 계정 데이터 수정·삭제·업로드 권한은 요청하지 않습니다. 모든 저장한 타인 목록·나중에 볼 동영상·YouTube 시청 기록을 가져오는 기능은 아닙니다.
- 새 YouTube 읽기 범위는 Google 검증 전이며 일반 배포 기능으로 검수 완료된 상태가 아닙니다. Google 안내에 따라 숨겨진 개인 시험 경로에만 연결했습니다. Google의 확인되지 않은 앱 안내가 표시될 수 있습니다.

## 저장과 백업

저장곡·보기 선택·소리 설정은 현재 브라우저의 기기에 보관합니다. 기존 자두 상태·대화 기록도 지우지 않습니다. 다른 기기나 브라우저와 자동 동기화하지 않습니다.

목록 제목 오른쪽 ‘⋯ → 저장목록 내보내기’로 Jadu-playlist.json을 보관하고, ‘저장목록 가져오기’로 복원합니다. 가져오기는 현재 자료를 바꿀 수 있으므로 먼저 내보내세요. 백업에는 개인 음악 주소와 이전 대화가 포함될 수 있으니 공개 저장소에는 올리지 마세요.

목록 삭제에는 확인 창이 있습니다. 웹앱은 실제 음악 파일을 다운로드하거나 PC 파일을 삭제하지 않습니다. 브라우저 사이트 자료를 지우면 저장곡이 사라질 수 있습니다.

## Brave

버튼이 모두 반응하지 않으면 이 사이트의 Brave ‘스크립트 차단’ 설정을 확인하세요. 스크립트 실행이 필요하며 광고·추적 차단과 별개입니다. 사용자는 스크립트 차단을 끈 뒤 검색·설정이 동작하고 기존 버전에서 화면을 잠가도 재생이 이어지는 것을 확인했습니다. 이번 화면 변경 후의 실제 아이폰 잠금 재생은 별도 기기 확인이 필요합니다.

[Brave 연결 안내](https://kt-soft.github.io/Jadu-Web/?v=20261105-more10&brave=1)는 공개 자두 주소만 전달합니다. 계정 정보·음악 목록·대화는 자동 전송하지 않습니다. 브라우저마다 저장 자료와 로그인은 따로 보관됩니다. 로그인 창이 열리지 않을 때는 ‘연결 취소’로 자두 화면에 돌아올 수 있습니다. 자두에 Brave의 광고 차단 엔진을 내장한 것은 아니며, 모든 광고 차단이나 백그라운드 재생을 보장하지 않습니다.

## 검색과 재생

공개 영상 제목·주소는 기존 자두 검색 서버로 조회합니다. 저장목록이나 로그인 정보는 검색 서버에 보내지 않습니다. 검색키 입력과 추가 서비스 가입은 필요하지 않습니다. YouTube 재생과 검색에는 인터넷이 필요합니다.

## 확인한 범위

2026-11-05 PC 브라우저를 직접 조작해 양쪽 검색, 썸네일 곡 선택, 실제 YouTube 재생·일시정지, 검색/영상 복귀, 검색/저장 목록 전환, 보기 체크박스, 공식 YouTube 로그인 화면 연결, 야옹 재생과 소리 끄기·새로고침 후 유지를 확인했습니다. 기존 저장곡 3개가 유지되는 것을 확인했습니다. 390×844 세로, 844×390 가로, 1280×720 화면을 확인했으며 실제 아이폰 검수와 구분합니다.

## 그림·소리 출처

기존 자두 그림·소리를 사용하며 원래 권리를 유지합니다. 전체 프로젝트를 오픈소스 라이선스로 선언하지 않습니다. ‘야옹’은 tuberatanka의 cat meow II(CC0)를 사용합니다. 원본 고지와 나머지 음원 출처·라이선스는 [음원 고지](https://kt-soft.github.io/Jadu-Web/assets/pet/audio-licenses.json)에 유지합니다.

## 이번 변경 확인

목록 제목 한 번 클릭으로 실제 영상 재생, 행별 삼각형 제거, 체크박스 선택 시 일시정지 유지, YouTube 로고의 현재 창 썸네일 복귀, 전체·음악 목록과 자두 최근 재생, 오른쪽 저장곡 3개 유지, 홈 썸네일 재생을 PC 브라우저에서 직접 조작했습니다. 기존 Google 계정의 실제 로그인 복원과 새로고침 후 유지, 기본 화면과 개인 시험 화면의 권한 분리, 연결 중 취소와 복귀, 검색 20개, 제목 한 번 클릭 후 실제 영상 재생·정지·썸네일 복귀를 PC 화면에서 직접 조작했습니다. 백업에 계정·접근 토큰 항목이 없는 것도 확인했습니다. 기존 127.0.0.1 시험 주소의 저장곡 3개는 유지했습니다.

YouTube Data API 사용 설정과 youtube.readonly 범위 등록은 기존 Jadu Web 프로젝트에서 완료했습니다. 결제수단·유료 전환은 하지 않았습니다. 이 PC는 새 Google 로그인 창을 만들 때 Windows 창 리소스 오류가 발생했으므로, 새 권한 동의와 실제 개인 재생목록 조회는 아직 끝까지 검증하지 못했습니다. 폰 Brave의 개인 시험 화면에서 마지막 연결 확인이 필요합니다. 연결 완료·아이폰 검수 완료로 보고하지 않습니다.

Google API 접근 토큰은 현재 탭의 세션 공간에만 짧게 보관하며 백업·검색 서버·GitHub로 보내지 않습니다. 기기의 저장곡과 Google 로그인 자료는 별도로 유지합니다. 개인정보 안내에 실제 처리 내용을 적었습니다.

## 폰의 검은 재생 화면 수정 (player9)

곡을 고르기 전에는 YouTube 조작 스크립트만 준비합니다. 내용 없는 숨겨진 동영상 재생기를 먼저 만들지 않습니다. 곡을 누른 순간 해당 영상 주소가 들어 있는 공식 iframe을 만들고, 실제 재생이 확인되면 재생 중으로 표시합니다. 이미 준비된 재생기에 곡을 바꿀 때는 첫 요청 전에 비동기 대기를 넣지 않습니다.

영상 가까이에 준비·오류 안내와 ‘다시 재생’을 표시합니다. 조작 연결이 지연돼도 공식 영상과 기본 재생 버튼은 남기며, 다시 재생은 현재 재생기 하나만 새로 만듭니다. Google 로그인·읽기 연결·기기 저장 자료의 처리 방식은 바꾸지 않았습니다.

PC에서 실제 곡 제목을 눌러 처음부터 재생, 정지/계속 재생, 재생 불가 영상의 오류 표시, 다시 재생 후 재생기 하나 유지, 오류 영상에서 정상 곡으로 전환을 직접 조작했습니다. 첫 곡은 234.561초 영상에서 7.273685초 재생, 전환 곡은 191.701초 영상에서 14.576625초 재생을 확인했습니다. 기존 로그인 복원도 확인했습니다. 사용자는 이전 account8에서 폰 로그인이 된다고 알려 주었으나 검은 화면이 남는다고 보고했으며, 사용자가 player9 수정본을 실제 폰 Brave에서 열어 영상이 보이고 재생되는 것을 확인했습니다.

공식 임베드와 제어 API를 사용합니다: [YouTube 재생기 매개변수](https://developers.google.com/youtube/player_parameters), [IFrame API](https://developers.google.com/youtube/iframe_api_reference). 첫 재생에 브라우저가 직접 확인을 요구하면 영상 안의 기본 재생 버튼을 눌러야 할 수 있습니다. Brave 보호 기능이나 폰의 보안 설정을 임의로 변경하지 않습니다.
광고가 재생 중일 때 실패로 단정하지 않도록, 대기 안내는 화면이 검게 멈춘 경우에만 다시 재생하도록 표현합니다.

## 검색 이어 보기 (more10)

검색 목록과 홈 분류 썸네일에 ‘더 보기’를 추가했습니다. 한 번에 최대 20개씩 이어 보며 기존 순서와 스크롤 위치를 유지합니다. 새 검색·분류 전환 시 이전 요청은 취소해 결과가 섞이지 않게 합니다. 재생 중 결과를 추가해도 현재 영상을 다시 만들지 않습니다. 최근 재생은 기존 기기 기록 범위를 유지합니다.

PC 실제 화면에서 검색 20→40→59개(중복 제외), 홈 분류 20→40개, 추가 조회 중 새 검색 전환, 영상 주소 단일 결과의 버튼 숨김, 영상 재생 중 결과 추가를 직접 조작했습니다. 재생 시간은 이어지고 새 재생기가 생기지 않는 것을 확인했습니다. 이번 이어 보기의 실제 아이폰 동작 확인은 PC 검수와 구분합니다.
