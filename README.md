# 자두 음악 웹앱

아이폰 Safari에서 열고 홈 화면에 추가해 사용하는 자두입니다. 음악은 **파일이 아닌 YouTube 주소**를 저장합니다.

현재는 공개 전 준비본이라 실제 접속 주소가 없습니다. 계정 로그인 연결은 준비 중이며, 지금 작동하는 저장 방식은 **이 기기에 저장**입니다. 기기 간 자동 동기화는 제공하지 않습니다. 실제 아이폰 Safari 재생·잠금 화면 동작은 아직 별도 확인이 필요합니다.

## 아이폰 홈 화면에 추가

1. 공개 후 안내받은 주소를 **Safari**로 엽니다.
2. **공유 → 홈 화면에 추가**를 누릅니다.
3. **웹 앱으로 열기**가 보이면 켜고 **추가**합니다.
4. 홈 화면의 자두 아이콘으로 실행합니다.

웹앱은 IPA 서명이나 7일마다 앱 서명을 갱신할 필요가 없습니다. 사이트 이용 가능 여부와 저장 자료 보존까지 영구 보장되는 것은 아닙니다.

## 사용하기

- **음악:** YouTube 영상·재생목록 주소를 넣고 곡을 선택합니다. 노래 저장은 주소를 보관합니다.
- **화면:** 세로는 영상 위·목록 아래, 가로는 영상 왼쪽·목록 오른쪽입니다.
- **자두:** 말을 걸거나 머리·배·꼬리·앞발을 만집니다. 설정에서 크기·말투·소리·음량을 바꿉니다.
- **먹이:** 츄르와 밥은 처음에 50개씩입니다. 먹거나 마시는 10초 동안 다른 먹이·행동이 잠깐 잠깁니다.

YouTube 재생에는 인터넷이 필요합니다. 재생 가능 여부·광고·자동재생·백그라운드 재생은 YouTube와 Safari의 동작에 영향을 받습니다. 네이티브 앱과 같은 재생을 보장하지 않습니다. 자두 대화는 기본 규칙·단어 사전이며 웹 AI 추론은 포함하지 않습니다.

## 내보내기·복원

1. **설정 → 저장 자료 → 저장 자료 내보내기**를 누릅니다.
2. **Jadu-playlist.json**을 파일 앱 등 본인이 관리하는 곳에 보관합니다.
3. 복원할 기기에서 **설정 → 저장 자료 → 저장 자료 가져오기**로 그 파일을 선택합니다.

가져오기는 현재 목록·설정·자두 상태를 바꿀 수 있으므로, 먼저 현재 자료도 내보내세요. 백업에는 개인 음악 주소·최근 대화가 들어갈 수 있습니다. 공개 저장소에 올리지 마세요. 다른 브라우저나 다른 사이트 주소로 열면 기존 자료가 보이지 않을 수 있습니다.

## 오프라인·자료 삭제 주의

처음에는 인터넷에 연결해 그림·소리와 화면을 충분히 읽어야 합니다. 읽어 둔 자료는 캐시가 남아 있으면 일부 오프라인에서도 사용할 수 있습니다. YouTube 음악은 오프라인 저장하지 않습니다.

Safari 웹 사이트 데이터·캐시 삭제나 저장 공간 정리로 저장곡·설정·대화·오프라인 자료가 사라질 수 있습니다. 초기화나 캐시 삭제 전에 **저장 자료 내보내기**를 먼저 하세요.

## GitHub Pages 공개 준비

빌드 없이 **dist/**만 게시합니다. 실제 저장소 생성·사이트 공개는 아직 진행하지 않았습니다. GitHub Free의 Pages는 공개 저장소가 필요하므로 소유자가 소스·그림·소리의 공개 범위를 확인하고 승인한 뒤 진행합니다.

승인 후 저장소 소유자가 **Settings → Pages → Source → GitHub Actions**를 지정하고, **Actions → Deploy Jadu Web to Pages → Run workflow**를 실행합니다. 성공한 실행에 표시된 **github-pages** 주소를 사용합니다. 실수로 공개하지 않도록 워크플로는 수동 실행만 설정했습니다.

[Pages 이용 범위](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [공식 배포 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 출처

기존 자두 그림·소리를 사용합니다. 그림이나 프로젝트 전체를 오픈소스 라이선스로 공개한다고 선언하지 않습니다. 원래 권리와 공개 범위는 별도입니다.

음원 저작자·출처·라이선스·편집 내역은 [음원 고지](dist/assets/pet/audio-licenses.json)에 있습니다. 물 마시는 소리는 tim.kahn 자료의 CC BY 4.0 표기를 보존하며, 나머지 음원도 각 고지를 유지합니다.



## 현재 연결 정보

- 웹 전용 저장소: https://github.com/KT-SOFT/Jadu-Web
- 게시 예정 주소: https://kt-soft.github.io/Jadu-Web/ (배포 성공 전에는 접속되지 않습니다.)
- Google 로그인 전용 Firebase Auth 프로젝트 jadu-web을 무료 Spark로 등록했습니다. 데이터베이스와 클라우드 목록 저장은 사용하지 않습니다.
- 브라우저 공개 연결 정보는 auth-config.js에 있으며 비밀번호·서버 비밀키가 아닙니다.
- 기존 네이티브 코드·원본 사진·개인 저장 목록은 공개 패키지에 포함하지 않습니다.
