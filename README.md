# 자두 음악 웹앱

**[자두 열기 — https://kt-soft.github.io/Jadu-Web/](https://kt-soft.github.io/Jadu-Web/)**

아이폰 Safari에서 열고 홈 화면에 추가해 사용합니다. 음악은 **파일이 아닌 YouTube 주소**를 저장합니다. 재생은 자두 안에서 유지합니다.

## 홈 화면에 추가

1. 위 주소를 **Safari**로 엽니다.
2. **공유 → 홈 화면에 추가**를 누릅니다.
3. **웹 앱으로 열기**가 보이면 켜고 **추가**합니다.
4. 홈 화면의 자두 아이콘으로 실행합니다.

IPA 설치나 7일마다 앱 서명을 갱신하는 절차는 필요하지 않습니다.

## 사용하기

- **음악:** 노래 제목·가수를 검색하면 자두 안에 실제 YouTube 결과가 최대 20개 표시됩니다. 영상·재생목록 주소를 붙여 넣어도 됩니다. **노래 저장**은 주소를 보관합니다.
- **화면:** PC판과 같은 버튼 문구·순서와 연보라색 창을 사용합니다. 유튜브 검색줄·곡 제목·가수 표시와 작은 재생 버튼을 맞췄습니다. 세로는 영상 위·목록 아래, 가로는 영상 왼쪽·목록 오른쪽입니다.
- **자두:** 작은 캐릭터와 대화 입력칸이 바로 보입니다. 말을 걸거나 머리·배·꼬리·앞발을 만집니다. 설정에서 크기·말투·소리·음량을 바꿉니다.
- **먹이:** 츄르와 밥은 처음에 50개씩입니다. 먹거나 마시는 10초 동안 다른 먹이·행동이 잠깐 잠깁니다.
- **유튜브 계정:** 영상 위 **로그인**을 누르면 새 탭에 공식 YouTube 화면이 열립니다. 계정을 확인하고 자두 탭으로 돌아옵니다. 유튜브 계정 상태를 자두가 대신 표시하지 않습니다.

음악 주소·목록·설정·자두 상태·최근 대화는 **현재 기기에 저장**됩니다. 유튜브 계정과 별개로 각 기기의 저장목록을 보관하며 다른 기기와 자동 동기화하지 않습니다. 음악 목록을 저장하는 클라우드 데이터베이스는 사용하지 않습니다.

YouTube 재생에는 인터넷이 필요합니다. 공식 유튜브 재생기의 광고를 제거하거나 잠금 화면·다른 앱에서 강제 재생하는 기능은 제공하지 않습니다. 설정의 **Brave에서 자두 열기**로 같은 자두 화면 전체를 Brave에서 시험할 수 있습니다. 개별 노래를 밖으로 넘기지는 않습니다. 자두 대화는 기본 규칙·단어 사전이며 웹 AI 추론은 포함하지 않습니다.

## Brave에서 같은 자두 사용

[Brave 연결 화면](https://kt-soft.github.io/Jadu-Web/?v=20261105-search5&brave=1)을 아이폰에서 열거나 **설정 → Brave에서 자두 열기**를 누릅니다. 설치된 Brave 앱을 여는 연결이며, 공개 자두 주소만 전달합니다. 음악 목록·대화·계정 정보는 자동으로 전송하지 않습니다.

Brave 안에서 같은 자두 화면을 사용합니다. 브라우저마다 저장 자료와 로그인은 따로 보관되므로 필요한 목록은 기존 브라우저에서 내보내고 Brave의 자두에서 가져옵니다. 자두 자체에 Brave의 광고 차단 엔진을 내장한 것은 아닙니다. 실제 아이폰에서 광고 차단과 화면 잠금 후 재생이 되는지는 확인이 필요합니다.

## 내보내기·복원

1. **설정 → 저장 자료 → 저장 자료 내보내기**를 누릅니다.
2. **Jadu-playlist.json**을 파일 앱 등 본인이 관리하는 곳에 보관합니다.
3. 복원할 기기에서 **설정 → 저장 자료 → 저장 자료 가져오기**로 그 파일을 선택합니다.

가져오기는 현재 목록·설정·자두 상태를 바꿀 수 있으므로 먼저 현재 자료도 내보내세요. 백업에는 개인 음악 주소·최근 대화가 들어갈 수 있습니다. 공개 저장소에 올리지 마세요. 다른 브라우저나 사이트 주소로 열면 기존 자료가 보이지 않을 수 있습니다.

## 오프라인·자료 삭제 주의

처음에는 인터넷에 연결해 그림·소리와 화면을 충분히 읽어야 합니다. 읽어 둔 자료는 캐시가 남아 있으면 일부 오프라인에서도 사용할 수 있습니다. YouTube 음악은 오프라인 저장하지 않습니다.

Safari 웹 사이트 데이터·캐시 삭제나 저장 공간 정리로 저장곡·설정·대화·오프라인 자료가 사라질 수 있습니다. 초기화나 캐시 삭제 전에 **저장 자료 내보내기**를 먼저 하세요.

검색은 별도 자두 검색 서버가 공개 영상 제목·주소를 가져옵니다. 저장목록과 로그인 정보는 검색 서버에 보내지 않습니다. 추가 검색 서비스 가입이나 검색키 입력은 필요하지 않습니다.

## 현재 확인 상태

PC 브라우저에서 직접 검색 입력·곡 선택·재생·일시정지·저장 후 새로고침·삭제 취소·크기 설정·점프 대화·영상과 목록 표시 전환을 조작했습니다. 유튜브 계정 버튼을 눌러 기존 로그인 계정이 표시되는 공식 YouTube 화면과 뒤로가기 복원을 확인했습니다. 390×844 세로와 844×390 가로 화면을 확인했습니다. 새 화면의 실제 iPhone Safari와 잠금 화면 재생은 별도 확인이 필요합니다.

[웹 전용 GitHub 저장소](https://github.com/KT-SOFT/Jadu-Web)에서 공개 자료를 확인할 수 있습니다. 사이트는 정적 파일로 제공하며 기존 Windows·아이폰 네이티브 앱과 별도입니다.

## 그림·소리 출처

기존 자두 그림·소리를 사용합니다. 그림이나 프로젝트 전체를 오픈소스 라이선스로 공개한다고 선언하지 않습니다. 원래 권리와 공개 범위는 별도입니다.

음원 저작자·출처·라이선스·편집 내역은 **[음원 고지](https://kt-soft.github.io/Jadu-Web/assets/pet/audio-licenses.json)**에 있습니다. 물 마시는 소리는 tim.kahn 자료의 CC BY 4.0 표기를 보존하며, 나머지 음원도 각 고지를 유지합니다.

## 아이폰 버튼 미동작 확인용 갱신

화면 동작을 한 파일로 묶어 불러오며, 시작 실패 시 상단에 다시 불러오기 안내를 표시합니다. 검색 버튼은 글자 입력 이벤트만으로 잠기지 않으며, 양쪽 검색칸 근처에 검색 중·완료·오류가 표시됩니다. PC 브라우저의 390×844 화면에서 설정·두 검색칸·실제 재생과 일시정지·기존 저장목록·삭제 취소를 조작했습니다. 사용자가 신고한 실제 iPhone의 버튼 미동작이 해결됐는지는 기기 재확인이 필요합니다.
